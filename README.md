Proyecto de migracion del equipo de termocarboxiterapia S Carbox de PIC + Nextion a STM32G431 + DWIN.

- Firmware: proyecto STM32CubeMX inicial en `Firrmware/`.

Ver `hardware/README.md` para el detalle de archivos de EasyEDA, BOM y Gerbers.
